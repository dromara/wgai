## 🎡 项目介绍
**WGAI** 是一款融合了 OpenCV、YOLO、OCR、数字人、AGV自动导航、人脸识别、语音识别等多种内核的综合 AI 管理平台。国内top10支持离线化工业级多模态AI平台。
* **架构优势**：训练与识别完全分离，有效避免内存与 GPU 过度消耗，支持自主离线化部署。
* **核心功能**：支持在线标注训练、边缘视频、语音分析盒/OCR/ChatGPT/数字人/AGV 全栈服务器支撑。
